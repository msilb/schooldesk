# Suggested request to the school / ClassOwl

This is a draft for a parent to send. The project has not sent it or obtained
permission for a ClassOwl connector.

> I would like to use a private school dashboard that organizes information
> already available through my own parent account: notices, dates, enrolled
> clubs, relevant documents and class memories.
>
> Do you offer a supported parent API, calendar/feed subscription, export or
> approved integration method? If not, do you permit a parent-operated program
> to make a bounded, read-only daily check through their own account?
>
> It would not send school messages, make bookings, change registrations or
> access another family’s account. It would respect your request limits and
> stop on login errors or rate limits. Please advise on permitted credential or
> session handling, hosting/storage, and displaying images/videos privately.
>
> I would also like to share the dashboard’s application code as open source.
> The repository contains fictional examples only; it does not distribute
> school documents, school branding, personal email, children’s information or
> real media. Each family would operate its own private installation.
>
> Could you confirm the permitted approach and any conditions before we develop
> or enable a connector for other parents?
